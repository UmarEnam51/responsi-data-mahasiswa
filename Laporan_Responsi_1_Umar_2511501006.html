2. Pemetaan & Integrasi Materi Perkuliahan
Materi Perkuliahan Bentuk Implementasi pada Proyek Dashboard Akademik
HTML Dasar & Semantik Penggunaan elemen semantik (<aside>, <header>, <main>, <footer>), elemen formulir pendaftaran mahasiswa dengan validasi input, tabel data terstruktur, dan komponen modal HTML.
CSS Styling & Responsive Skema warna institusi akademik modern (Navy & Sky Blue), desain responsif menggunakan media query untuk perangkat mobile/tablet/desktop, badge predikat IPK (Cumlaude, Sangat Memuaskan), serta animasi hover tombol.
Bootstrap CSS Pemanfaatan grid system responsif (row, col), utility classes (shadow-sm, rounded-4, p-3), serta komponen siap pakai: Card, Table, Modal, Button, Badge, Toast, dan Dropdown.
JavaScript Dasar Penggunaan Array of Objects untuk entitas data mahasiswa & riwayat KHS, fungsi modular kalkulasi IPK berdasarkan SKS dan bobot nilai, serta percabangan logika kondisi (if/else, switch case).
DOM JavaScript & jQuery Manipulasi DOM dinamis, penanganan event buka-tutup sidebar secara dinamis, serta efek animasi pudar (fade-in) jQuery pada tabel data setiap kali filter atau pencarian berubah.
React JS (React 19) Pembangunan aplikasi modular berbasis komponen (App, Sidebar, Navbar, StatCards, StudentTable, StudentModal, GradeModal, DeleteModal), pengelolaan state dengan useState & useEffect, serta persistensi LocalStorage.
3. Ringkasan Fitur Unggulan yang Diterapkan
  1. Operasi CRUD Lengkap:
    • Create: Registrasi mahasiswa baru dengan validasi NIM unik dan data wajib.
    • Read: Tampilan tabel responsif lengkap dengan avatar inisial, badge prodi, semester, IPK, dan status aktif.
    • Update: Form modal edit data mahasiswa yang terisi otomatis secara reaktif.
    • Delete: Konfirmasi keamanan sebelum menghapus data mahasiswa.
  2. Fitur Khusus Studi Kasus — Modal Input Nilai / KHS: Admin dapat menginputkan mata kuliah baru, SKS, dan nilai huruf (A s.d. E) dengan kalkulasi otomatis IPK & akumulasi SKS secara real-time.
  3. Live Search & Multi-Filter: Pencarian instan berdasarkan NIM atau Nama mahasiswa, filter program studi, filter status mahasiswa (Aktif, Cuti, Lulus, Non-Aktif), dan sorting IPK.
  4. Stat Cards (Ringkasan Statistik): Kartu ringkasan total mahasiswa, mahasiswa aktif, rata-rata IPK, dan jumlah kandidat lulusan berpredikat Cumlaude.
  5. Penyimpanan Data Lokal (LocalStorage): Data tersimpan secara persisten pada browser sehingga tidak hilang saat halaman dimuat ulang (refresh).
